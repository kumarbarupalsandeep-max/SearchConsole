Google Search Console ke features ki sahi jaankari ke liye pehle Google ke official pages dekhein. Features aur reports badal sakte hain, isliye final audit ke waqt links dobara check karein.

## General jaankari
- [Search Console Help](https://support.google.com/webmasters/) — Search Console ke features aur unhe use karne ki help.
- [Google Search Central](https://developers.google.com/search) — Google Search ke liye website banane aur sudharne ki guide.
- [Search Console API](https://developers.google.com/webmaster-tools) — code ke zariye supported Search Console data use karne ki documentation.
- [API references ki list](https://developers.google.com/webmaster-tools/v1/api_reference_index) — API ke available features aur endpoints.
