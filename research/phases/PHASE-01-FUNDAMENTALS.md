## Google Search Console kya hai?
Google Search Console (GSC) Google ka free tool hai. Isse website owner dekh sakta hai ki uski website Google Search mein kaise dikh rahi hai, kitne clicks aa rahe hain, kaunse pages Google ke index mein hain aur Google ko kuch pages tak pahunchne mein dikkat to nahi.

## Yeh tool kya nahi karta?
1. Yeh guarantee nahi deta ki har page Google mein aa jayega.
2. Yeh top ranking ya traffic ki guarantee nahi deta.
3. Yeh website ki har technical problem khud theek nahi karta.
4. Yeh har search query, link ya problem wale URL ki poori list nahi dikhata.
5. Yeh website par visitor kya karte hain, uski har detail nahi batata.

## Zaroori words ka simple matlab
| Word | Aasaan matlab |
|---|---|
| Property | Website ya website ke ek hisse ko GSC mein add karna |
| Domain property | Domain aur uske subdomains ko cover karne wali property, Google ke rules ke hisaab se |
| URL-prefix property | Ek khaas URL se shuru hone wale addresses ki property |
| Crawling | Googlebot ka page khol kar uski jaankari lena |
| Indexing | Google ka page ko process karke search database mein rakhna |
| Impression | Search result ka user ko dikhna, report ke counting rules ke mutabik |
| Click | Search result par click hona |
| CTR | Clicks ka impressions ke mukable percentage |
| Canonical URL | Similar pages mein preferred/main URL |
| Sitemap | URLs ki file jo Google ko pages dhoondhne mein help karti hai |
| Manual Action | Google ki team ka policy issue par liya gaya action |
| Security Issue | Hacking ya harmful content jaisi security problem |

## Shuruaat kaise karein?
1. Search Console kholein aur sahi website add karein.
2. Google ke diye gaye tareeke se ownership verify karein.
3. Confirm karein ki property mein sahi URLs cover ho rahe hain.
4. Google ko data jama karne ka samay dein.
5. Overview aur messages dekhein.
6. Zaroorat ho to sitemap submit karein.
7. Important pages inspect karein aur reports ko time-time par dekhein.

## Example
Aapki website par 50 pages hain. Search Console kuch pages ke clicks, impressions aur indexing ki jaankari de sakta hai, lekin har report mein sabhi 50 pages ya har search query dikhna zaroori nahi.

## Yaad rakhein
Data update hone mein time lag sakta hai aur har report har property ke liye available nahi hoti. Notes padhna kisi live website ka audit karne ke barabar nahi hai.
