## What is Search Console?
Google Search Console (GSC) is a Google service that helps site owners monitor how their website appears in Google Search, inspect indexing, submit sitemaps, review crawling, and discover certain security, manual-action and structured-data issues.

## What it is not
- It does not guarantee that every page will be indexed.
- It does not guarantee rankings or traffic.
- It is not a complete replacement for analytics tools that measure on-site behavior.
- It does not show every query, backlink or affected URL.
- It does not automatically fix website errors.

## Core vocabulary
| Term | Simple meaning |
|---|---|
| Property | Website or URL scope added to Search Console |
| Domain property | Property covering the verified domain and its subdomains/protocols under Google's rules |
| URL-prefix property | Property for URLs matching a specific prefix |
| Crawl | Googlebot fetches a page |
| Index | Google's searchable collection of processed pages |
| Impression | A result was shown under the report's counting rules |
| Click | A user clicked a result |
| CTR | Clicks divided by impressions, as a percentage |
| Canonical | Preferred URL among duplicate or similar pages |
| Sitemap | File listing URLs a site wants search engines to discover |
| Manual action | Human-applied action for a policy violation |
| Security issue | Detected compromised or harmful content concern |

## Main areas
1. Overview and Insights.
2. Performance reports.
3. Indexing and URL Inspection.
4. Sitemaps.
5. Crawl Stats and robots.txt.
6. Manual Actions and Security Issues.
7. Links report.
8. Enhancements and structured data.
9. Core Web Vitals and HTTPS.
10. Removals, SafeSearch, Change of Address and settings (Phase 11 pending).

## Getting started
1. Open Search Console and add the correct property.
2. Verify ownership using a supported method.
3. Confirm the property covers the intended URLs.
4. Allow time for data collection.
5. Review Overview and messages.
6. Submit a sitemap if appropriate.
7. Inspect important URLs and monitor reports.

## Limitations
Data freshness, report availability, URL samples and permissions vary. A documentation summary is not a live audit.

## Aasaan Hindi (Hinglish) mein samjho

Google Search Console website owner ke liye Google Search ka report card hai. Isse pata chalta hai ki website Google par kaise dikh rahi hai aur Google ko page samajhne ya access karne mein koi dikkat to nahi. Yaad rakho: report theek hone ka matlab top ranking ya har page ka Google mein aana pakka nahi hai.

**Example:** Example: Agar aapki website par 50 pages hain, to Search Console kuch pages ke clicks, impressions aur indexing ki jankari de sakta hai. Har report mein har page ya har search query dikhna zaroori nahi.
