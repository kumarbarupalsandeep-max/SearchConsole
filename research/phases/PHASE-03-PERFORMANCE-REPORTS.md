## Performance report kya batati hai?
Yeh reports batati hain ki Google ke search products se log aapki website tak kaise aa rahe hain.

## Main reports
1. **Search Results:** Google Search mein website ki performance.
2. **Discover:** Google Discover se aane wale traffic ki jaankari, jab report available ho.
3. **Google News:** Google News ke covered sections se judi performance.

Search Results ke andar News search type aur alag Google News report ek hi cheez nahi hain.

## Metrics ka matlab
| Metric | Aasaan matlab |
|---|---|
| Clicks | Search result se website par kitne clicks aaye |
| Impressions | Result kitni baar dikhaya gaya |
| CTR | Impressions ke mukable clicks ka percentage |
| Average position | Report ke rules ke hisaab se average position ka andaaza; har user ki fixed rank nahi |

## Filters aur dimensions
Report ke hisaab se aap queries, pages, countries, devices, dates aur search appearance dekh sakte hain. Date range, comparison aur export jaise options bhi ho sakte hain. Har option har report mein ho, yeh zaroori nahi.

## Report kaise check karein?
1. Sahi date range choose karein.
2. Clicks, impressions, CTR aur average position dekhein.
3. Milte-julte time periods compare karein.
4. Queries dekhkar samjhein ki log kya search kar rahe hain.
5. Dekhein kaunse pages ki performance badhi ya ghati.
6. Zaroorat ke hisaab se country, device ya search type filter karein.
7. Aage analysis ke liye data export karein.
8. Website updates, season aur search demand ke saath trends compare karein.

## Example
Agar result 1,000 baar dikhaya gaya aur 50 clicks aaye, to CTR 5% hai. Average position ka matlab yeh nahi ki har user ko result usi rank par dikhega.

## Zaroori baatein
1. Privacy ki wajah se kuch queries report mein nahi dikhayi ja sakti.
2. Data late update ho sakta hai.
3. Traffic badhne ya ghatne ki ek hi wajah maan lena sahi nahi.
4. Discover report tabhi available ho sakti hai jab Google ke paas kaafi eligible data ho.
5. API data par bhi aggregation aur row limits ho sakti hain.
