## Link ke types
- **External link / backlink:** Doosri website se aapki website par aane wala link.
- **Internal link:** Aapki website ke ek page se usi website ke doosre page ka link.
- **Anchor text:** Woh clickable text jis par user click karta hai.
- **Top linked page:** Report ke data mein zyada links paane wala page.
- **Top linking site:** Doosri website jahan se aapki site ko links mile hain.

## Links report mein kya mil sakta hai?
Report mein external links, zyada linked pages, links dene wali websites, anchor text aur internal links ki jaankari mil sakti hai. Yeh poore internet ke har link ki complete list nahi hoti.

## Report kaise use karein?
1. Sahi website property select karke Links report kholein.
2. Dekhein kaunse pages ko links mil rahe hain.
3. Links dene wali websites ke relevant examples check karein.
4. Anchor text dekhein aur unusual patterns ko samjhein.
5. Internal links check karein ki important pages tak pahunchna aasaan hai ya nahi.
6. Zaroorat ho to tables export karein.

## Limitations aur savdhani
1. Report sample dikha sakti hai; har link aur real-time data zaroori nahi milta.
2. Links ko website/domain ke hisaab se group kiya ja sakta hai.
3. Report mein row limits ho sakti hain.
4. Alag backlink tools ke results unke apne crawlers aur data ki wajah se alag ho sakte hain.
5. Sirf kisi unknown ya low-quality lagne wale domain ko dekhkar link disavow na karein. Google ke mutabik disavow tool aam taur par advanced cases ke liye hai, khaaskar jab unnatural links ka bada issue ho.

## Internal link check-list
1. Important pages ko relevant pages se links mile hon.
2. Navigation aur breadcrumbs samajhne layak hon.
3. Important page bina kisi link ke akela na reh gaya ho.
4. Broken links aur bekaar redirect chains fix hon.
5. Link ka clickable text page ke topic ko samjhata ho.
6. Internal links preferred canonical URL par jaate hon.

## API ki baat
Yeh assume na karein ki Search Console API poori Links report ka data deti hai. API docs mein support confirm karein; warna UI/export option use karein.

## Example
Home page se product page par link internal link hai. Kisi doosri website se aapke blog par link backlink hai. Report mein link na dikhne ka matlab hamesha yeh nahi ki link exist nahi karta.
