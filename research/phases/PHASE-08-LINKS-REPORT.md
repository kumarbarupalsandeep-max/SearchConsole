## Link terminology
- **External link/backlink:** link from another website to your site.
- **Internal link:** link from one page on your site to another.
- **Anchor text:** clickable text associated with a link.
- **Top linked page:** a page receiving many links in the report sample.
- **Top linking site:** an external site grouped in the report as linking to your property.

## Main sections
The Links report may include external links, top linked pages, top linking sites, top linking text, internal links and detail views for selected rows.

## How to use the report
1. Open Links for the correct property.
2. Review top linked pages to learn which content attracts links.
3. Review top linking sites and inspect relevant examples.
4. Review anchor text for context and unexpected patterns.
5. Review internal links to see whether important pages are discoverable.
6. Export tables when offline review is useful.

## Limitations
- The report is a sample, not a complete real-time backlink database.
- Links may be grouped by site/domain and canonical behavior.
- Tables have row limits and may not expose every link attribute.
- Third-party backlink tools can differ because their crawlers and datasets differ.
- The report alone is not a complete orphan-page audit.
- Do not disavow links only because a domain is unfamiliar or looks low quality. Google's guidance generally reserves disavowal for advanced cases involving substantial unnatural links and a manual action or clear risk.

## Internal-link audit checklist
- Important pages have contextual internal links.
- Navigation and breadcrumbs are logical.
- Key pages are not orphaned.
- Broken links and unnecessary redirect chains are repaired.
- Anchor text is descriptive and relevant.
- Internal links point to preferred canonical URLs.

## API note
Do not assume the standard Search Console API exposes the full Links report. Use UI/export options unless official API documentation explicitly supports the desired data.
