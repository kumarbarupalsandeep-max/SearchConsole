**Status: PENDING RESEARCH.** This file is a planning checklist, not a completed phase. Do not treat the items below as verified current UI behavior until the research is completed against official Google documentation.

## Topics to research
1. Removals tool: temporary removals, outdated content/cache requests, SafeSearch-related requests and request status.
2. Change of Address: when it is appropriate for a site move, prerequisites, redirects and sitemap/canonical preparation.
3. Settings: ownership verification, users and permissions, associations, crawl-related settings, robots.txt and other property settings where available.
4. Property management: domain vs URL-prefix property differences, adding/removing properties and ownership verification methods.
5. Data export and API access: supported endpoints, authentication, quotas and limitations.
6. Workflow examples and common mistakes.
7. Official Google documentation references and date of review.

## Completion criteria
- Every topic has a plain-language explanation.
- Current feature availability and limitations are verified from official documentation.
- Temporary removal is clearly distinguished from permanent removal/deindexing.
- Site migration guidance emphasizes redirects, canonical consistency, sitemaps and monitoring.
- Live property checks are kept separate from documentation research.
