## Manual Actions vs Security Issues
| Area | Meaning |
|---|---|
| Manual Actions | Google has applied a manual action for a policy violation |
| Security Issues | Google has detected signs of hacked, deceptive or harmful content |

These reports are different. A clean report does not prove every possible security risk is absent.

## Manual Actions
Possible categories include unnatural links, thin or spammy content, cloaking, sneaky redirects, hidden text/keyword stuffing, structured-data abuse, third-party spam, site reputation abuse and other policy violations. The current list may change.

### Recovery workflow
1. Open the Manual Actions report.
2. Read the issue and affected scope carefully.
3. Identify the underlying policy violation.
4. Fix affected pages and the broader pattern, not just one sample URL.
5. Document changes and evidence.
6. Submit a reconsideration request when the report offers that option.
7. Monitor review status and follow further instructions.

A reconsideration request should be specific and honest. Removing a manual action does not guarantee ranking or traffic recovery.

## Security Issues
Concerns can include hacked pages, injected content, harmful downloads, deceptive pages, phishing-like content or harmful redirects.

### Incident response
1. Restrict compromised access and rotate credentials.
2. Enable multi-factor authentication where possible.
3. Identify the compromise vector and affected files/pages.
4. Remove malicious code, content, redirects and backdoors.
5. Patch CMS, plugins, frameworks and server software.
6. Review logs and restore from a trusted backup if needed.
7. Test the cleaned site and request review when available.
8. Continue monitoring for reinfection.

## Important cautions
- Do not ignore alerts because the homepage looks normal.
- Hacked sites may contain malicious URLs not linked from the homepage.
- Avoid deleting evidence before understanding the incident.
- A manual action is not the same as an algorithmic ranking change.
- A clean report does not replace normal security monitoring.
