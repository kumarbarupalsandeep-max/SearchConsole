## Dono mein kya farq hai?
| Topic | Aasaan matlab |
|---|---|
| Manual Action | Google ki team ko Search policy ka issue mila aur usne action liya |
| Security Issue | Website par hacking, dhokha dene wale pages ya harmful content ka risk mila ho sakta hai |

Dono alag hain. Report saaf hone se yeh prove nahi hota ki har security risk khatam hai.

## Manual Action kin wajah se ho sakta hai?
Google ki policies ke khilaaf unnatural links, kam ya spam content, cloaking, chhupaya hua text, keyword stuffing, galat structured data aur doosre spam patterns issue ban sakte hain. Categories badal sakti hain.

### Manual Action fix karne ke steps
1. Manual Actions report kholein.
2. Issue aur affected pages ki details padhein.
3. Policy ka asal issue samjhein.
4. Sirf ek page nahi, balki jahan same problem hai wahan bhi fix karein.
5. Kiye gaye changes ka record rakhein.
6. Report option de to reconsideration request bhejein.
7. Review status check karte rahein.

Request mein sachchi aur specific details dein. Manual Action hatne se ranking ya traffic wapas aane ki guarantee nahi.

## Security Issue ki examples
Website hack ho jana, page mein harmful code aa jana, fake login page, harmful download ya visitor ko galat jagah bhejna.

### Security problem aane par kya karein?
1. Compromised access ko secure karein aur passwords/keys badlein.
2. Jahan mumkin ho multi-factor authentication chalu karein.
3. Pata karein kis file ya page par problem hai.
4. Harmful code, content aur redirects hataein.
5. CMS, plugins, framework aur server software update karein.
6. Logs check karein; zaroorat ho to trusted backup se restore karein.
7. Clean website test karein aur option mile to review request karein.
8. Dobara hacking hone ke signs par nazar rakhein.

## Example
Agar website hack hui hai, to sirf warning ko ignore karna ya homepage dekhkar maan lena ki sab theek hai, sahi nahi. Harmful pages aur asal security problem fix karni hogi.

## Savdhani
1. Homepage normal ho sakta hai, lekin doosre pages hacked ho sakte hain.
2. Problem samjhe bina evidence delete na karein.
3. Manual Action aur algorithm se ranking badalne mein farq hai.
4. Saaf report regular security monitoring ka replacement nahi.
