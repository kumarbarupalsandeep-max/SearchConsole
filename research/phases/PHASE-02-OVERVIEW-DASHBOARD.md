## Overview kya hai?
Overview ek summary screen hai. Yeh website ki alag-alag reports aur kuch alerts ki important jaankari ek jagah dikhati hai. Har website par ek jaise cards dikhna zaroori nahi.

## Search Console Insights
Insights website ke content aur search performance ko aasaan tareeke se samajhne mein help karta hai. Availability ke hisaab se clicks, impressions, popular pages, badhte-ghatte trends, queries aur traffic sources jaisi jaankari mil sakti hai.

## Recommendations aur achievements
1. **Recommendations:** Kuch sudhar ya agle steps suggest kar sakti hain. Yeh ranking ki guarantee nahi hain.
2. **Achievements:** Traffic ya milestones se judi progress dikha sakti hain. Yeh SEO score nahi hain.

## Messages aur notifications
Messages mein website se judi important updates, problems ya guidance aa sakti hai. Naye messages check karein aur zaroori kaam apni task list mein likh lein. Kya message dikhega, yeh access aur current interface par depend kar sakta hai.

## Annotations
Annotations chart par note lagane ka tareeka hai. Isse aap record kar sakte hain ki kis date ko website update, migration ya content release hua tha. Yeh feature har jagah available ho, yeh zaroori nahi.

## Kaise use karein?
1. Sahi website property select karein.
2. Naye messages aur zaroori alerts dekhein.
3. Overview cards check karein.
4. Insights mein content ke trends dekhein.
5. Kisi change ki wajah samajhne ke liye detailed Performance report kholein.
6. Zaroorat ho to major updates ki date note karein.

## Example
Agar clicks kam ho rahe hain, Overview se iska signal mil sakta hai. Asal wajah jaanne ke liye Performance report mein purani aur nayi date, pages aur queries compare karein.

## Aam galtiyan
1. Recommendation ko ranking ki guarantee samajhna.
2. Sochna ki har property par same cards honge.
3. Achievement ko SEO score samajhna.
4. Overview normal dekhkar messages ignore karna.
