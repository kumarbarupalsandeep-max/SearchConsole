## Overview dashboard
The Overview page gives a high-level summary of relevant reports and alerts. Depending on property data and feature availability, cards can include performance, indexing, experience, enhancements, manual actions, security issues or recommendations. Not every card appears for every property.

## Search Console Insights
Insights provides a simplified view of content and search performance. Depending on availability, it may show clicks, impressions, top content, trending content, queries, countries and traffic sources. Open the detailed Performance report for deeper analysis.

## Recommendations and achievements
Recommendations can highlight issues, opportunities or configuration steps. They are optional guidance and do not guarantee rankings. Achievements may highlight milestones or traffic-related progress; they are not an SEO score.

## Messages and notifications
Messages can notify users about important property events, issues and guidance. Review new messages regularly and record actionable work in a tracker. Available actions and message visibility may depend on current interface and permissions.

## Annotations
Annotations help explain changes in performance charts, such as a migration or content release. Use concise dated notes. Feature availability and editing/deletion behavior can change, so confirm in current UI documentation.

## Suggested workflow
1. Select the correct property.
2. Review new messages and critical alerts.
3. Check Overview cards.
4. Use Insights to identify content trends.
5. Open detailed reports to investigate changes.
6. Record major releases and migrations with dated notes where annotations are available.

## Common mistakes
- Treating recommendations as ranking guarantees.
- Assuming every property has identical cards.
- Treating an achievement as an SEO score.
- Ignoring messages because Overview looks normal.
- Assuming a summary contains every affected URL.
