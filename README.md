## Purpose
A beginner-friendly, structured reference for understanding Google Search Console (GSC), its reports, workflows, limits, and practical troubleshooting. The notes distinguish documented product behavior from checks that still require access to a real Search Console property.

## How to Use This Repository
1. Start with the master research document.
2. Read phase files in numerical order.
3. Use the official references to verify current product behavior.
4. Treat examples as illustrative unless a source explicitly says otherwise.
5. Do not assume that a report exists for every property or that a valid status guarantees indexing, ranking, or rich-result display.

## Research and Verification Rules
- Prefer official Google Search Central, Search Console Help and Google Developers documentation.
- Feature availability and report layouts can change.
- Search Console reports may show samples rather than every URL.
- Documentation research does not prove that a particular website/property is configured correctly.
- Live verification, screenshots, account permissions and current property-specific results remain separate tasks.
