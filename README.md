3. `research/REFERENCES.md` — Google ke official help pages aur technical links.
4. `research/STATUS.md` — complete aur pending kaam ki list.

## Notes kaise padhein?
1. Sabse pehle main guide padhein.
2. Phases ko 1 se 11 tak number ke hisaab se padhein.
3. Kisi feature ki latest jaankari ke liye uska official Google link kholein.
4. Examples sirf samjhane ke liye hain; unhe aapki website ka actual result na samjhein.
5. Report mein koi issue na dikhne ka matlab yeh nahi ki website mein koi issue ho hi nahi sakta.

## Research ke zaroori rules
1. Jahan mumkin ho, Google ki official documentation ko pehle dekhein.
2. Google apne features aur reports ko badal sakta hai.
3. Kuch reports mein har URL ya har search query nahi dikhayi jaati.
4. Documentation padhne se yeh prove nahi hota ki koi khaas website sahi set up hai.
5. Live website check karne ke liye actual access ya check ki ja sakne wali evidence chahiye.
6. Phase 11 aur final research audit abhi baaki hain.
